Interactive Explainer · Process Maps

Variants, Step Overlap & Cross Lane Transitions

A Process Map links up to 5 objects into a tree with one primary (root) object. For each process instance (one primary record), Process Monitor builds the variant: the set of unique leaf orderings. It also precalculates Step Overlap and Cross Lane Transitions for the swimlane Process Graph. Edit the map, drag the record timelines, and every calculation below updates.

One process instance: a single primary record plus its related records. Each bar segment is a state, snapped to time periods. Wider segments mean longer time in the state. The instance has one primary record because variants are calculated per primary record.

4 · Precalculated interactions

Step overlap & cross lane transitions

Overlap: steps of directly related records (parent ↔ child) whose time interval intersects this step's interval. Cross lane transition: in a leaf ordering, the next state entry after this step belongs to a different lane. Tags show record pairs · average start delay in periods. Click a row to select the step.
